# Format naskah Reel

Gunakan tabel ini untuk setiap Reel. Satu baris = satu adegan. Kolom "Rujukan" menautkan klaim ke tabel klaim.

## Lembar ringkas

| Bidang | Isi |
|---|---|
| Judul kerja | |
| Sasaran pembaca | |
| Tujuan | Edukasi / Trafik konsultasi / Kunjungan |
| Pembawa acara | |
| Durasi target | |
| CTA tunggal | |
| Perlu tinjau apoteker/dokter | Ya / Tidak (alasan) |

## Shot list

| Shot | Sudut/gerak | Lokasi | Properti | Catatan privasi |
|---|---|---|---|---|
| A | Close-up tangan | Meja konseling | Kemasan obat bebas (merek ditutup bila perlu) | Tidak ada resep/layar terlihat |

## Paket unggahan

- **Teks sampul:** ≤6 kata, terbaca di grid
- **Caption:** (baris pertama = inti) …
- **Tagar (3–5):** …
- **Alt text/subtitle:** …
- **Waktu tayang yang disarankan:** dari data akun sendiri (analitik), bukan tebakan
